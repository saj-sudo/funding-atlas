    What this is

    A registry, not advice. Each row is one program page or federal notice read by a connector; the status and dates are what that source said on the run date. Blank fields mean the source did not state the value. Nothing is inferred and nothing is guessed, which is why some states say "no state sources yet": the connectors for them have not been built.

    The relevance tiers (likely, possible) are rule-based readings of each record, written as SQL you can audit. Argue with the rules, not the records.
