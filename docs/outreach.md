# Outreach: routes, the note, the log

The registry is live (https://saj-sudo.github.io/funding-atlas/) and Maryland has eight agencies, so the next action
on the roadmap is a conversation, not a connector. This file holds what that takes: who to write to, what to say, and
who has been written to. Answers decide what gets built next (the roadmap's "the town names the next agency").

## Routes, in order (decision 2026-10-15, restated 2026-11-03)

1. Five small-town administrators whose towns recently received a DHCD or MHT award (the award lists on
   dhcd.maryland.gov and mht.maryland.gov name them).
2. Maryland Municipal League staff.
3. Rural councils of governments: Tri-County Council for Western Maryland, Tri-County Council for Southern Maryland,
   Tri-County Council for the Lower Eastern Shore, Mid-Shore Regional Council, Upper Shore Regional Council.
4. Grant Professionals Association, Maryland chapter; ELGL (Engaging Local Government Leaders).
5. The Governor's Grants Office.

Then Virginia and Delaware by the same routes once a Maryland conversation has happened.

## The four questions (the page footer, `scripts/build_site.py` `READER_QUESTIONS`)

## The note (route 1, a town administrator; drafted 2026-11-03, not yet sent)

Fill in the three brackets. Keep it under a screen; the ask is five minutes and one answer.

```
Subject: A page that lists what your town can apply for, and a way to be told when it changes

Hi [name],

I'm Saj, a data manager in Maryland building a small open tool on my own time, and [Town] came up because of your
recent [DHCD/MHT] award. I'd like five minutes of your reaction, not a meeting.

The tool reads state agency and federal grant pages every day and keeps one list of what a Maryland town can apply to
right now, with the deadline and who's eligible, as the agency states it. Maryland's page:
https://saj-sudo.github.io/funding-atlas/md/

It also publishes a change log you can subscribe to, so instead of checking agency sites you get told when a round
opens, closes or reopens: https://saj-sudo.github.io/funding-atlas/md/feed.xml (works in Outlook, any feed reader, or
Slack's RSS app).

If you look at it once, I'd want to know:
1. What is open right now that is not on this page?
2. Which rows should not be here, and why?
3. Which columns do you actually use when deciding whether to apply? Which are noise?
4. Where do you look for this today, and what does that source get right that this one does not?

Even one answer helps. The code and every rule are public, so if something is wrong I can fix it the same week.

Thanks,
Saj
```

Variants for routes 2 to 5 are the same note with the second paragraph's opener changed: "the League's members",
"the Council's towns", "your members", "the agencies the Office points towns to". Write them when route 1 has produced
one reply, so the reply shapes them.

## What to expect them to find (so the reply is not a surprise)

- The Maryland page shows the open and forecasted rows a town can apply to, federal rows included, and a collapsed
  "between rounds" group of recent closed state programs. Blank fields mean the agency's page did not say.
- Known gaps a reader may name first: GOCPP's law-enforcement rounds (the office blocks crawlers; ask them for a
  feed), Main Street Improvement Grant (tagged nothing because the page never says "municipality"), MDOT's SHA
  programs on roads.maryland.gov (not read), MDEM's HMGP/BRIC/EMPG (not on its roster yet).
